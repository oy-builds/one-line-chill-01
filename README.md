# One Line, One Chill

A make.fun entry for "One Line, One Chill": a single sentence of horror, 110
characters, about a child whose drawings quietly stop including her father —
weeks before she starts calling someone else in the house "Dad".

`main.ts` (Node 22, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> My daughter's drawings stopped including me three weeks before she started calling the man in the attic 'Dad.'

Run it with `node main.ts`.
